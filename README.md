One short line about office life — a single joke with a setup and a turn, built for make.fun's "The Funniest Office Joke, Judged Head to Head" bounty ($2 in USDC). The program writes the joke to `/output/entry.txt`.

The joke: "I survived a meeting that could've been an email by replying all: 'Per my last email, this meeting.'"

## Run it

```sh
python3 main.py
```

Writes one line (100 characters, no trailing newline) to `/output/entry.txt`. Set `OUTPUT_DIR` to write elsewhere for local testing.
